# Rust_ai_agent

A lightweight, high-performance Rust applications built to solve llm ai integration in database administion.
This workspace code base of two application writing in pure Rust.
-AI agent connecting llms in meta-ai repository
-MCP server which give tools and ressouces to agent-llm in mcp_server repository

## 🚀 Features

- **Efficient & Fast**: Leverages Rust's memory safety guarantees and compile-time optimization.
- **Extensible**: Built with a modular architecture allowing easy addition of new features or modules.

## 🛠️ Installation

### Prerequisites

- [Operating System, e.g., macOS , Linux or windows ]
- [Tool, e.g., Rust 1.65.0+]

### Step-by-Step Setup

1. Clone the repository:
   ```bash
   git clone repository
   cd <mcp_server or meta-ai-agent> 
   ```

2. Install Rust:
   ```bash
   rustup toolchain install stable
   rustup default stable
   ```

3. Verify installation:
   ```bash
   cargo --version
   ```

4. Build the project:
   ```bash
   cargo build --release
   ```

## 📦 Usage

### Running the Application

Execute the binary from your project directory:

```bash
./target/release/meta-ai-agent
```

Or run it in a terminal (note: this is a demo, ensure it has a `main.rs` entry point):

```bash
cargo run
```
